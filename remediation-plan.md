# План усунення проблем GDPR Compliance для системи розумного будинку

remediation_plan:
  phases:
    - name: "Негайні дії"
      duration: "0-7 днів"
      actions:
        - "Призначити відповідального за privacy та security"
        - "Переглянути всі облікові записи користувачів і права доступу"
        - "Вимкнути зайвий збір даних там, де це можливо"
        - "Підготувати коротке privacy notice"

    - name: "Короткострокові дії"
      duration: "7-14 днів"
      actions:
        - "Визначити правову підставу для кожної категорії даних"
        - "Реалізувати granular consent для необов’язкової обробки"
        - "Підготувати процедуру реагування на інциденти"
        - "Задокументувати процес обробки запитів щодо прав користувачів"

    - name: "Зберігання і видалення"
      duration: "14-30 днів"
      actions:
        - "Визначити строки зберігання для відео, журналів і резервних копій"
        - "Налаштувати правила автоматичного видалення"
        - "Реалізувати workflow для права на видалення"
        - "Додати можливість експорту даних користувача"

    - name: "Покращення безпеки"
      duration: "14-30 днів"
      actions:
        - "Забезпечити HTTPS/TLS для всіх інтерфейсів"
        - "Покращити рольовий контроль доступу"
        - "Захистити резервні копії шифруванням"
        - "Розширити audit logging для критичних дій"

    - name: "Управління відповідністю"
      duration: "30-60 днів"
      actions:
        - "Провести DPIA"
        - "Задокументувати records of processing"
        - "Перевірити сторонні інтеграції"
        - "Провести повторний аудит відповідності"

  priorities:
    critical:
      - "Granular consent"
      - "Retention policy"
      - "Право на видалення"
      - "План реагування на інциденти"

    high:
      - "Privacy notice"
      - "Мінімізація даних"
      - "Шифрування"
      - "Контроль доступу"

    medium:
      - "Audit logging"
      - "Перенесення даних"
      - "Процедура виправлення"

## Очікуваний результат

Після усунення проблем система повинна забезпечувати:
- чітку правову підставу
- прозоре privacy notice
- збір лише мінімально необхідних даних
- визначені строки зберігання
- реалізацію прав користувачів
- сильніші заходи безпеки
- задокументовану підзвітність
